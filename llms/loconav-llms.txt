# LocoNav

> LocoNav is an AI- and IoT-powered GPS vehicle tracking and smart fleet management platform (50+ countries, 2,200+ device/sensor types). The LocoNav Integration API exposes REST endpoints and webhooks for fleet telematics: GPS/sensor telematics, video telematics and live streams, driver/vehicle/trip/geofence/user management, vehicle scorecards, immobilization, live-share links, and real-time alert & live-location webhooks. Auth is a user-level token in the `User-Authentication` header; listings are paginated (page/perPage); time values are epoch seconds; rate limit is 500 req / 60s.

## APIs
- [LocoNav Integration API — Developer Docs](https://developers.loconav.com/): REST + webhooks; base URL https://api.a.loconav.com/integration/api/v1
